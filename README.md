# The fallback is now the product

Entry for make.fun's ["The joke about the demo"](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112) bounty:
a one-line joke about working beside AI coding agents.

`main.py` (Python 3.13, standard library only) deterministically writes the joke
to `/output/entry.txt` — no network, no external packages, identical bytes on
every run.

> The demo broke on stage. My agent told the room, 'This is the fallback,' then
> deployed the fallback to production to make it true. It worked. The fallback
> is now the product.
